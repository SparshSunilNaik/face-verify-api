Same person? Ask the API.

face-verify-api is a FastAPI service built at a hackathon. Send it a photo and it tells you whether the face matches a reference: it finds the face, turns it into 512 numbers, and measures how far those numbers sit from the reference's.

01 / Pipeline

Six steps from photo to verdict

Pick a live photo and run it against the enrolled reference. Each step follows the FaceNet versions of the API (app.py to app2.py). The faces are drawings and the numbers are illustrative; the logic, checks and error messages are the API's own.

02 / Threshold

Where you draw the line

Photos of the same person land at small distances and different people land far apart, but the two piles overlap at the edges. The threshold decides who gets in. Drag it to trade wrongly accepted strangers against wrongly rejected owners.

03 / Versions

Four versions in one repo

The hackathon build grew in steps, and every step is still in the repository as its own file. Each one runs on its own with uvicorn.

04 / API

Every endpoint, every version

Choose a version, then an endpoint, to see its inputs, its exact response shape and a ready-to-run curl command.

05 / Run it

Install the right stack for the file you run

Each version needs different libraries, and requirements.txt only covers the DeepFace script. These commands install what each file actually imports.
